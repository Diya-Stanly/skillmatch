# SkillMatch — Resume Analyzer & Job Description Matcher

SkillMatch is a browser-based resume analysis tool that helps job seekers evaluate how closely their resume matches a job description. It identifies matching and missing keywords and calculates a match percentage to help users improve their resume's relevance.

## ✨ Features

- 📄 Upload resumes in PDF and TXT formats
- 📝 Enter or paste a job description
- 🎯 Calculate a resume-to-job-description match percentage
- ✅ Identify matched keywords and skills
- 🔍 Highlight missing keywords and skills
- 💡 Provide suggestions to improve resume relevance
- 🌐 Simple, browser-based interface

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Diya-Stanly/skillmatch.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

No backend server is required for the basic frontend application.

## 🎯 Project Objective

The goal of SkillMatch is to help job seekers understand the keyword alignment between their resumes and target job descriptions, making resume customization easier and more structured.
